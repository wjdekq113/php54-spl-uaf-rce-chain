# Reproduction evidence

These files are generated by:

```bash
python3 lab/centos7/reproduce.py --build --evidence evidence
```

Top-level files:

- `manifest.json`: pinned image/source identity, package NEVRAs, binary hashes,
  Build IDs, tool versions, RPM verification, and native relocation;
- `results.json`: complete structured results for the five cases, including the
  request-by-request ASLR chain;
- `run.log`: short human-readable summary;
- `SHA256SUMS`: recursive hashes for every generated evidence file and this
  evidence-format document.

The `aslr-chain/` subdirectory contains:

- `heap-leak.bin`: invariant 101-byte `SplObjectStorage` bootstrap body;
- `trigger.bin`: final 176-byte `ArrayObject` `del_ref` body for that run;
- `trace.json`: ordered metadata for all 15 FastCGI requests, including payload
  and response hashes, read addresses and lengths, short cells, and transport
  disposition;
- `result.json`: calculated PHP/libc/loader/pthread bases, Build ID and static
  file fingerprints, system GOT equality, marker disposition, and worker
  replacement.

Verify the committed chain offline without starting PHP:

```bash
python3 lab/centos7/verify_evidence.py --evidence evidence/aslr-chain
```

Runtime PIDs, ASLR bases, random marker names, heap contents, and payload hashes
that embed addresses change between runs.  The invariants are:

- 101-byte heap leak and 176-byte read/exec shapes;
- address source recorded as exploit responses only;
- `proc_maps_used=false` and `proc_mem_used=false` for `aslr-rce`;
- PHP, libc, loader, and libpthread ELF/Build ID checks;
- system GOT target equals the derived libc `system()` address;
- final marker creation and FPM worker replacement;
- patched PHP 5.4.44 returns normally without a marker;
- every listed SHA-256 verifies.
